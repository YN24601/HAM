皮肤纤维瘤

（Dermatofibroma，DF）

临床表现
  • ✔ 硬质结节（直径＜1cm）
  • ✔ 典型凹陷体征（酒窝征）
  • ✔ 棕红至深褐色外观
  • ✔ 表面皮肤纹理清晰可见
  • ✔ 挤压时边缘外翻现象
危险等级
0%

※ 快速增长时需病理检测

治疗方案
保守治疗
  • 糖皮质激素局部注射
  • 液氮冷冻治疗
  • 脉冲染料激光
手术治疗
  • 椭圆切除术
  • 深部组织楔形切除
  • 全层缝合技术
动态观察
  • 每6个月测量直径
  • 数码照片对比监测
  • 痛觉变化追踪
预防建议
  • 避免虫咬等皮肤外伤
  • 减少下肢剧烈摩擦
  • 女性注意经期激素波动
  • 遗传易感者定期筛查
