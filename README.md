# 1.需求分析

- 患者
  - 注册、登陆、注销

  - 查看医生信息
  - 查看预约信息
  - 预约医生
  - 取消预约
  - 皮肤病预测
  - 查看皮肤病预测记录
  - 查看诊疗记录
- 医生
  - 登陆、查看个人信息、修改登录密码
  - 查看患者信息
  - 查看预约信息
  - 诊疗（皮肤病预测）
  - 查看诊疗记录

  - 管理患者信息
  - 管理预测记录（患者）
  - 管理诊疗记录（医生）
  - 数据统计
